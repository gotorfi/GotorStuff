Animation Service

The purpose of the AnimationService module is to manage animations and allow any animation to be stopped from anywhere in the game. It can also prevent the 255 AnimationTrack limit because the module manages and removes old animations automatically.

DataStore Service

Here are two different datastore systems. The one on the left is a mix of an older and newer coding style. Nowadays I mainly use tables instead of storing values inside IntValue objects. In some cases IntValues can still be useful, like in this example, but I personally prefer keeping most of the data directly inside the datastore rather than distributing it into IntValue instances.

Smooth First-Person Camera

This First Person Camera system was made for the Rojam 2026 game project. The system is short and clean, and all settings are placed at the top of the script to make value adjustments easy. The camera system also includes a RayCast system that prevents the camera from clipping through walls.

ShopService (Backend)

ShopServiceScript was created for my game RUINED.. Its purpose is to manage the entire shop rotation and maintain shop offers dynamically. The script collects data from modules and decides how the offers should behave. This is the backend code for the shop system in RUINED.
